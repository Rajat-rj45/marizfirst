# MarizFirst

MarizFirst is a production healthcare appointment marketplace for verified doctors, hospitals, and clinics.

## Current MVP Direction

The platform will use a hybrid appointment booking model.

Patients can select visible appointment slots, but final confirmation will be handled by MarizFirst admin or partner users.

## Core Modules

- Public website
- Doctors listing
- Doctor profile
- Hospitals listing
- Hospital profile
- Clinics listing
- Clinic profile
- Appointment booking
- Admin dashboard
- Partner dashboard
- Blog and SEO system
- WhatsApp notification flow

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Role-based access control
- WhatsApp Business API integration later
